## 🌟 주요 특징 (Key Features)

- **8문항 초정밀 가중치 알고리즘**:
  - 축당 2문항(E-I, S-N, T-F, J-P)으로 총 8문항 구성
  - 4점 척도(`A+`, `A`, `B`, `B+`) 가중치 스칼라 점수제를 채택하여 1:1 동점 오류를 원천 차단하고 세부 백분율(%) 산출
- **감성적 글래스모피즘 & 리치 애니메이션**:
  - 배경에서 부유하는 4대 파스텔 플로팅 오브(Floating Orbs) 애니메이션
  - 문항 선택 시 0.18초 쾌속 자동 트랜지션
  - 3D 글래스 펄스 오브 기반의 분석 대기 로딩 연출
  - 결과 화면 진입 시 화려한 Canvas Confetti 폭죽 효과
- **16개 유형별 상세 분석 & 궁합**:
  - 직관적 별명, 1줄 정의, 핵심 성격 해설
  - 4개 축별 퍼센트 게이지 카운트업
  - 찰떡 케미 & 거리두기 케미 정보 제공
  - 원클릭 결과 링크 복사 토스트 알림
